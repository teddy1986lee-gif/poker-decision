# HOLDEM GOSU

테이블 상황을 보고 폴드·체크·콜·베팅·레이즈 중 가장 좋은 행동을 고르는 노리밋 홀덤 토너먼트 학습 웹게임 시제품입니다. 상황을 직접 만들어 승률을 확인하는 승률 시뮬레이터도 들어 있습니다. 모바일 화면을 기준으로 만들었습니다.

## 바로 실행하기

- 웹 주소: https://teddy1986lee-gif.github.io/poker-decision/
- 내려받은 파일로는 `docs/index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
- GitHub Pages 설정: 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main`으로 고르고 Save를 누릅니다. 폴더는 `/ (root)`와 `/docs` 중 어느 쪽이어도 됩니다. 루트로 지정하면 맨 위의 `index.html`이 게임(`docs/`)으로 넘겨 줍니다. 무료 계정은 공개 저장소에서만 Pages를 쓸 수 있고, 비공개 저장소에서 쓰려면 GitHub Pro 이상 요금제가 필요합니다.
- 일반 웹 버전에서는 기록과 이용권이 **그 브라우저에만** 저장됩니다. 여러 사람의 공유 랭킹과 친구 초대 보상 확인은 서버가 붙어야 동작합니다(Claude 아티팩트 버전은 공유 저장소를 씁니다).

## 들어 있는 기능

- 문제 300개를 한 테이블에서 출제: 처음엔 입문 위주로 나오고, 많이 풀수록 중급·고급 비중이 늘어납니다. 한 세트(3문제) 안에서는 쉬운 문제부터 나옵니다.
  - 입문(100): 포지션별 시작 핸드, 기본 팟오즈, 체크와 밸류 베팅
  - 중급(100): 3벳 대응, 드로우의 콜 판단, 베팅 크기, 턴 액션
  - 고급(100): 상대 범위 추정, 블러프 캐치, 숏스택, 버블과 ICM
- 승률 시뮬레이터(아래 메뉴 '승률')
  - 인원 2~8명, 내 패·상대 패·보드(플랍·턴·리버)를 카드 고르기 화면에서 직접 지정
  - 상대 패를 비워 두면 '모든 패' 또는 '상위 50·30·20·10·5%' 범위 안에서 계산
  - 계산할 경우의 수가 450만 번 이하면 전부 계산한 정확한 값, 그보다 많으면 6만 판 무작위 시뮬레이션
  - 플레이어별 승률(혼자 이길 확률·비길 확률), 스트리트별 내 승률 기록, 리버까지 완성될 족보 확률
  - 팟과 콜 금액을 넣으면 콜에 필요한 승률과 비교해 콜의 평균 손익 표시
  - 리버에서 가려진 상대 패를 범위 안에서 무작위로 한 번 열어 보기, 빠른 예시 8가지
- 세로형 포커 테이블 화면: 좌석·스택·베팅·보드·내 카드, 현재 족보 표시, 스트리트별 액션 기록
- 정답·해설: 권장 행동과 이유, 다른 선택의 문제점, 학습 주제
- 이용권: 하루 무료 3문제, 모의 보상형 광고(시청 완료 시 3문제), 친구 초대 보상(하루 3회)
- 포인트와 랭킹(이번 주·누적), 오답노트와 재풀이(랭킹 미반영), 닉네임 간편 로그인
- 관리자 페이지: 문제 검수 상태·정답·해설 수정, 새 문제 등록(자동 검증·미리보기), 보상 한도와 랭킹 기간 설정, 비정상 기록 검토, 핵심 지표 통계와 광고 매출 추정

## 빌드와 검증

Node.js 18 이상과 Python 3이 필요합니다.

```bash
node check.js          # 모든 문제의 팟·스택·차례·카드 중복·선택지·정답 검증
python3 build.py       # docs/index.html(웹용)과 dist/poker-decision.html(아티팩트용) 생성
```

생성기를 다시 돌리면 `problems/g1.js`~`g3.js`가 덮어써집니다.

```bash
node gen/l1.js   # 입문 70문제
node gen/l2.js   # 중급 60문제
node gen/l3.js   # 고급 70문제
```

## 문제 데이터 형식

```js
P({ id: 'B13', lv: 1, tp: '기본 팟오즈', ti: '턴 넛 플러시 드로우, 작은 베팅',
  bl: [500, 1000, 1000],   // SB, BB, BB 앤티
  s: 40,                   // 모두 40BB (또는 { d: 40, BTN: 22 })
  h: 'BTN', c: 'As5s', b: 'Ks8s3dJh',
  a: 'f f f f r2.2 c f f | b2 c | b2.7',   // UTG부터 차례대로, 스트리트는 | 로 구분
  o: ['f', 'c', 'r9', 'a'], ans: 1,         // 선택지와 정답(복수 가능: [1, 2])
  w: '권장 행동의 이유', n: ['선택지별 설명', ...], ctx: '필요할 때 상대 성향·상금 구조' });
```

액션 표기: `f` 폴드 · `x` 체크 · `c` 콜 · `bN` 베팅 N BB · `rN` 레이즈 총 N BB · `a` 올인

## 시제품이라 알아둘 점

- **정답은 전문가 검수 전 초안입니다.** 계산(팟오즈, 범위 대비 승률, 칩 기대값, ICM)으로 근거를 맞췄지만, 서비스 전에 포커 전문가 검수가 필요합니다. 관리자 페이지에서 문제별로 `검수 완료`를 지정하고, 설정에서 `검수 완료 문제만 출제`를 켤 수 있습니다.
- **광고는 모의 화면입니다.** 실제 광고와 매출은 없습니다. 실서비스에서는 웹 보상형 광고를 지원하는 광고사를 연동해야 합니다.
- **정답 판정·기록·보상은 실서비스에서 서버가 처리해야 합니다.** 지금은 브라우저(또는 아티팩트 공유 저장소)에서 처리합니다.
- 화면 디자인은 모바일 포커 앱의 일반적인 테이블 구성을 참고했고, 다른 회사의 로고·이름·캐릭터는 사용하지 않았습니다.

## GTO AI 코치

로비 카드·상단 AI 버튼에서 자유롭게 질문할 수 있는 채팅 화면과, 문제 풀이 후 현재 상황을 가져오는 질문 버튼을 추가했습니다. 대화 이어가기, 예시 질문, 새 대화, 요청 중단 및 오류 복구를 지원합니다.

**실제 AI 답변 활성화에는 별도 서버 배포와 API 키 설정이 필요합니다.** 현재는 연결 준비 상태입니다. [서버 설정 안내](server/README.md)를 따라 연결합니다. GTO 원칙에 따른 학습 해설이며 솔버 계산 기능은 아닙니다.
